# 比赛当天操作卡

赛前一次上传**8个运行文件（含run_state.py）**并完成实车标定，比赛中不改代码/参数/4×AA电池组；前超声手势选图或续跑。

1. **上电**：LED快闪3次。无有效存档时，手在前超声约5cm处靠近→完全移开N次选图1–4，每次短闪确认。移开应>13cm或离开测距范围；8–13cm不算新手势。没选图就一直停车。
2. **核号/放车**：移开静止2.5s，LED慢闪N次×2轮；不对就近距离保持2s清零。随后常亮5s，在此期间放到START、两探头在胶带内，前方净空；未净空则重新计时。
3. **有存档上电**：LOST双闪、FINISHED三闪，进入4s续跑窗口。**LOST（含意外掉电留下RUNNING）不操作会自动按原进度续跑**，核号后还有5s放车；FINISHED不操作则正常选图。

## 丢线了怎么办

1. 车停下、LED双闪：放回**丢线处附近同一物理线段，车头朝原行驶方向**。
2. 停稳至少1s后，先移开前超声前的遮挡，再挥1次并移开，LED常亮3s后重新找线；倒计时需要持续新鲜的净空读数，手未移开或读数无效时重新计时。或同时拔掉USB/电池再上电，窗口什么都不做，4s后按原进度续跑，核号后5s内放好车。
3. 想回START重跑：挥2次，同路线进度清零。想换图：贴近保持2s，清存档后重新选路。复位本身不会清除保存进度。

| 手势 | 续跑窗口 / 停车后动作 |
|---|---|
| 挥1次 | 原路线原进度续跑；FINISHED时撤销最后一次FINISH消费（AFTER_TURNS转角进度不变），用于误判终点 |
| 挥2次 | 同路线从头开始，放回START |
| 贴近2s | 删除存档，回正常选路；STOP时软复位 |
| 窗口挥3次 | 仅已配置检查点时回最近已过检查点；默认列表为空，3次报错 |

REACQUIRE只重新找线：见黑恢复，否则有界转向→短直行试探→再搜索，次数耗尽仍停车；**不消耗转角/死路队列或改变跨隙进度**。没有定位能力，放到别的线段会错位。检查点由队伍实测填写。

| 地图 | 预期动作 |
|---|---|
| 1 矩形 | 北向出发，RRR；计划后线尾仅±25°检查，无线停车 |
| 2 迷宫 | RRRLLRRRRR，十字直行；十弯后线尾仅±25°检查，无线停车 |
| 3 坡道/间隙 | LLR前完全忽略超声；之后墙前刹车→左转约60°→斜跨间隙，见黑续行；超时/终点停车 |
| 4 arm | 默认右沿；J1第一腿第一次死路掉头，回主线到J2进中腿，第二次死路停车 |

| LED | 含义 |
|---|---|
| 快闪3次 / 手势短闪1次 | 已启动 / 记下一次挥手 |
| 双闪循环 / 三闪循环 | LOST丢线停车或续跑窗口 / FINISHED |
| 常亮1s / 快闪2s | 长靠近已清零 / 无效手势报错 |
| 快闪10次 / 核号前常亮2s | 前超声尚无VALID，仍可选图 / VSYS<3.6V，检查供电 |
| 慢闪N次×2轮 / 常亮 | 核号 / 放车倒计时；保持前方净空 |

**失回波策略不变**：仅障碍启用路段，500ms内曾≤25cm后，新NO_ECHO或<2.5cm立即触发路线障碍动作；未接近NO_ECHO可空旷行驶。STOP_WAIT接近锁存需>30cm再畅通500ms，或持续新鲜NO_ECHO3s后慢速恢复1s。完成掉头/跨隙转向或已完成累计45°转向也清旧锁存。3号60°只按标定时间估算，无实测航向保证。

**赛前**：全表面IR黑=1；矮块10–30cm读VALID；抬轮查方向，再落地查制动/转角/跨隙/分岔。菜单6在Pico实测存档平均耗时，>40ms时赛前设SAVE_ON_EVENTS=False，拔电源前必须等停车存档完成；主机时间不代表闪存延迟。默认时间均需标定。

**标定专用LED**：菜单1/2完成=慢闪3次后常亮，故障=快闪10次后熄灭。拔USB运行，重接读calibration_last.txt；不代表实车赛道验收。
